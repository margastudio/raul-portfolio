# Imágenes necesarias

Coloca aquí las imágenes optimizadas (recomendado: .webp o .jpg comprimido):

- hero.jpg              -> imagen principal del Home
- about-hero.jpg        -> imagen principal de About
- brands/brand-1.png ... -> logos de marcas (fondo transparente PNG)
- albums/{slug}.jpg     -> imagen de portada de cada álbum (usa los slugs de messages/en.json -> albums.items)
- albums/{slug}/1.jpg, 2.jpg, ... -> fotos dentro de cada álbum

Todas las imágenes deben servirse desde este proyecto (no desde framerusercontent.com),
para que el sitio cargue rápido y sin bloqueos en China continental.
