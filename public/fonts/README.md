# Fuentes locales

Coloca aquí tus archivos .woff2:
- display.woff2  (fuente para títulos/headlines)
- sans.woff2     (fuente para texto en inglés)
- zh.woff2       (fuente para texto en chino simplificado, ej. Noto Sans SC / PingFang)

No se usa Google Fonts: las fuentes deben autohospedarse aquí para
evitar bloqueos y demoras de carga en China continental.
